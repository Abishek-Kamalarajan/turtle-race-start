# Turtle Race

A simple betting game built with Python's `turtle` graphics module. Six turtles line up at the start line, you bet on which color wins, and they race to the finish line at random speeds.

## How to run

```
python main.py
```

You'll be prompted to enter the color you're betting on (Red, Green, Yellow, Black, Purple, or Orange). Click the race window to close it once the race finishes.

## Requirements

- Python 3
